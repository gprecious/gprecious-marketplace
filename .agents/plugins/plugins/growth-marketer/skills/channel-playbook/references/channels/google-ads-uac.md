# Google Ads / UAC Channel Reference

## When to Choose

Use Google Ads when search intent, app-install intent, YouTube reach, or Google Display inventory can connect users to the service. Search works best for high-intent categories; App campaigns work best when an app has store assets and enough conversion signal for install or in-app optimization.

## Targeting

- Search: group keywords by intent, not only by product feature.
- Display: separate cold prospecting from remarketing and use message angles appropriate to awareness level.
- App campaigns: provide text, image, video, location, language, bid, budget, and store listing assets.
- For B2B SaaS, separate commercial-intent searches from educational searches and send them to different CTAs.

## Budget and Bidding

- Search: bid around the value of the conversion event and isolate expensive high-intent terms.
- Responsive search ads need varied assets: pain, outcome, proof, offer, CTA.
- App campaigns for installs can begin with install volume. Move to in-app action optimization only when the event has enough stable volume.
- Display prospecting should be measured with assisted and view-through caution; remarketing should have stricter conversion KPIs.

## Creative Specs

- Search: headlines should reflect keyword language, service category, outcome, and proof.
- Display: use benefit visuals and clear product context.
- App campaigns: prepare short portrait video, landscape or square image, concise text assets, and store listing alignment.
- Landing pages should repeat the searcher problem language in the H1 or first screen.

## Measurement KPIs

- Search: conversion rate, cost per lead/signup/purchase, search term quality, impression share for priority terms.
- App campaigns: CPI, cost per trial_start, cost per purchase, D7 retention, store listing conversion rate.
- Display: cost per qualified visit, assisted conversion, remarketing CPA, creative-level conversion quality.
